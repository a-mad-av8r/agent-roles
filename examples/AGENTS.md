# Example AGENTS.md

This project uses role-based steering.

- Writers own `docs/` and `content/`.
- Designers own `docs/posts/`, `docs/Articles/`, and `visuals/`.
- Backend engineers own `src/`, `scripts/`, and `tests/`.
- Operators own `ops/` and `infrastructure/`.

Before editing outside your role, create a handoff instead of guessing.
